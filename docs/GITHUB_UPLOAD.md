# GitHub upload checklist

1. Create a new **public** GitHub repository named `Autonomic-Lift-Truck-MAPE-K-Dataset`.
2. Extract this ZIP locally and upload the **contents of the top-level folder**, preserving the directory structure.
3. Before making the repository public, review the files and confirm the desired repository license. No license has been selected automatically in this package.
4. Do not publish the project passkey. Configure `AES_KEY` as a new 32-byte key in the execution environment when testing the Node-RED AES flow.
5. The four full demonstration videos are already linked from `evidence/online/README.md`; local supporting video files are also included under `evidence/videos/`.
6. After upload, copy the repository URL and provide it to the editorial office if requested. If a permanent archival identifier is later desired, a GitHub release can be archived in Zenodo or another research-data repository.

## Recommended repository description

> Minimal dataset, experimental evidence, software, and reproducibility materials for the MAPE-K Autonomic Intralogistics Mobile Robot study.
